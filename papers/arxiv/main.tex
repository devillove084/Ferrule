\begin{abstract}
Storage-backed inference needs bounded materialization and safe reuse, not
merely a small device cache. \system{} connects source-bound plans,
stage-local admission, exact completion identities, and physical custody to
bounded weight residency. Its next-expert pipeline and safe blocking control
use one positioned-read worker, a depth-one queue, identical host/device
limits, and the existing synchronous forward. Lookahead moves the next
selected read ahead of current compute submission; GPU overlap requires
correlated kernel activity, not host spans. Nine exact-once GPU qualification
gates pass on one frozen source cut, covering constructor/provider cells and
both schedules' full40, retained-fresh, ordinary and cold-owner factory paths.
Each full40 gate compares 1,986,560 vocabulary values; each ordinary run
matches all 64 actual output fingerprints of its same-schedule diagnostic
primary, without observing routes or states. Observed logical host charge and
allocator-accounting high-water remain within the declared limits, not
certified physical peaks or release proofs. Separately, one historical DEBUG
run records four HTTP successes, three limited canaries and 36,240,064,128
logical reader bytes; it is not current CLI quality or scheduling evidence.
We separate factory qualification, bounded accounting, I/O observability and
physical custody. Capacity-frontier, CLI/HTTP, paired performance and GPU
overlap qualification remain open; physical-memory necessity, nonblocking
forward and performance leadership are not claimed.
\end{abstract}
