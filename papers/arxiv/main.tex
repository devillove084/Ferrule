\begin{abstract}
Storage-backed inference requires more than a small weight cache: the live
working set must fit, nonresident data must become ready before consumption,
and asynchronous physical references must end before capacity is reused.
\system{} targets this problem with source-bound resource plans, staged
admission, generation-qualified completion, and explicit custody through
publication and retirement. We connect these contracts to a normal execution
walkthrough, structured lifecycle algorithms, implementation boundaries, and
four evaluation questions: capacity, request I/O, safe scheduling, and failure
custody. The available TP1 observation is one DEBUG-instrumented exploratory
run: four HTTP requests succeed, three limited visible-text/usage reference
canaries pass, and 30 decoder invocations record 36,240,064,128 logical
checkpoint-reader bytes. Hello2 has HTTP/usage checks only. Physical storage
traffic, complete numerical quality, and the final resource contract remain
unverified. Separate TP2 numerical receipts and two descriptive resident vLLM
comparison blocks do not close those TP1 gates or establish a fair speedup.
The same-contract safe blocking reference is not implemented. Thus the draft
provides a design and a scoped logical-demand observation, not a demonstration
of inference beyond physical memory capacity, measured overlap, universal
quality, or completed multimodal support.
\end{abstract}
